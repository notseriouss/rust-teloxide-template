# Rust Teloxide template

This template is a skeleton for building async telegram bots using rusts teloxide and tokio crates.
It contains prestructured code for most basic telegram bot features and has some useful *tips :) 


## Dependencies

**teloxide = { version = "0.17.0", features = ["macros"] }**
**tokio    = { version = "1.52.3", features = ["macros"] }**
***reqwest = { version = "0.12.28", features = ["socks"] }** 

> NOTE: 
> Crates' versions are the latest tested at the time of the last commit.
> 
> *not necessary - read the in-code comments
